# Projet-integre-2026
## 🎙️ Configuration du Modèle de Reconnaissance Vocale (Vosk)

Pour des raisons de performance et de quotas sur GitHub, le modèle d'IA **Vosk** n'est pas inclus dans le dépôt. Vous devez le télécharger et le placer manuellement.

### Étapes d'installation :

1. **Télécharger le modèle :**
   Rendez-vous sur le site officiel de Vosk et téléchargez la version légère américaine :
   👉 [vosk-model-small-en-us-0.15.zip](https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip)

2. **Extraire et placer le dossier :**
   Décompressez l'archive ZIP et déposez le dossier extrait **exactement** à l'emplacement suivant dans votre espace de travail :
   
   ```text
   📁 Projet-integre-2026/
   └── 📁 workspace/
       └── 📁 lib/
           └── 📁 vosk-model-small-en-us-0.15/  <-- Déposer le dossier ici
    ```
